# Contributing

Thanks for helping build agent-sudo.

## Development

Development should happen with the repository checked out locally or on a remote development host. Keep changes small and reviewable.

Before opening a pull request:

- run the test suite
- run formatting/lint checks
- update documentation when behavior changes
- avoid committing secrets, credentials, or private telemetry

## Pull requests

Please explain:

1. what changed
2. why it changed
3. how it was tested
4. any security implications

Security-sensitive changes should include threat-model notes and tests where practical.
