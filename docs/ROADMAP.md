# Roadmap

## Phase 0 — foundation

- repository documentation
- package skeleton
- common action schema
- policy format
- secure logging model

## Phase 1 — local CLI

- `agent-sudo <command>`
- child-process lifecycle management
- action/event capture
- structured decision records
- safe default policies
- tests

## Phase 2 — practical agent support

- Claude Code adapter
- Codex adapter
- OpenCode adapter
- MCP interception
- interactive approval flow

## Phase 3 — semantic decisions

- optional Jev integration
- typed decision contracts
- explainable reason codes
- latency and outcome metrics

## Phase 4 — developer experience

- web dashboard
- policy editor
- decision replay
- GitHub integration
- benchmark suite

The roadmap is intentionally subject to change as the project learns from real-world usage.
